# C Command-Line Calculator

A menu-driven calculator supporting addition, subtraction, multiplication and division.

## Compile and run
```bash
gcc calculator.c -o calculator
./calculator
```
On Windows with MinGW: `gcc calculator.c -o calculator.exe`, then run `calculator.exe`.

## Suggested caption
Created a menu-driven calculator in C with basic arithmetic operations, input validation and division-by-zero handling.
