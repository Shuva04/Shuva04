# Smart Clock

A responsive browser-based digital clock with live time, date, greeting and a light/dark theme toggle.

## Run
Open `index.html` in any modern browser. No build tools or dependencies are required.

## Features
- Live local time updated every second
- Full date and time display
- Greeting based on local time
- Light/dark theme toggle
- Responsive layout
