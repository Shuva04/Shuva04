# Spotify-inspired Music Player UI

A responsive music-player interface inspired by common streaming-app layouts. This is an original demo UI; it is not affiliated with Spotify and does not use Spotify's branding, API or catalogue.

## Run
Open `index.html` in a modern browser. The player uses a local demo audio file if you add one at `assets/demo.mp3`; otherwise the controls show a friendly setup message.

## Features
- Responsive sidebar and playlist layout
- Track selection and play/pause controls
- Progress display when a local audio file is present
- No API keys or external services required

## Add audio
Place audio you own or are licensed to use at `assets/demo.mp3`.
