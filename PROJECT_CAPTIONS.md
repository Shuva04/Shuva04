# Ready-to-use Project Captions

These captions describe the implementations currently present in this portfolio. Adjust them if your final project differs.

## 1. Breast Cancer Classification Demo
Developed an educational breast-cancer classification web application using Python, scikit-learn and Django. The demo accepts mean radius and mean texture as inputs and returns a dataset-class prediction through a simple web interface and JSON API. This is a learning prototype, not a clinical diagnostic tool.

**Tags:** #Python #MachineLearning #ScikitLearn #Django #DataScience

## 2. Smart Clock
Built a responsive Smart Clock using HTML, CSS and JavaScript. It displays live local time and date, provides a time-based greeting, and includes a light/dark theme switcher.

**Tags:** #HTML #CSS #JavaScript #WebDevelopment #Frontend

## 3. Spotify-inspired Music Player UI
Created a responsive music-player interface using HTML, CSS and JavaScript, with a playlist-style layout and browser audio controls. The project supports a user-provided local audio file and is an independent learning project, not affiliated with Spotify.

**Tags:** #JavaScript #FrontendDevelopment #HTML #CSS #WebDesign

## 4. Secure OTP Generator
Developed a command-line OTP generator in Python using the built-in secrets module for cryptographically secure numeric code generation. Added configurable length and input validation.

**Tags:** #Python #CyberSecurity #InformationSecurity #Programming

## 5. C Calculator
Created a menu-driven calculator in C supporting addition, subtraction, multiplication and division, with input checks and division-by-zero handling.

**Tags:** #CProgramming #Programming #ProblemSolving #BeginnerProjects

## 6. Real-Time Face Detection
Built a real-time face-detection demo using Python and OpenCV. The application processes webcam frames and draws bounding boxes around detected faces using a Haar cascade classifier. It detects faces only and does not identify people.

**Tags:** #Python #OpenCV #ComputerVision #AI #MachineLearning
